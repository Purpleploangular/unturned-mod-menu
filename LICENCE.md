## 🧩 About

**Unturned Mod Menu** is a curated list of Unturned open-source tools:

- **Overlays** — on-screen helpers, layout notes, world map viewer, loot tracker
- **Quality-of-Life Helpers** — inventory notes, config manager, radar notes
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Loot Tracker — log nearby item spawns for study
- World Map Overlay — read coordinates and landmarks
- Radar Notes — visualize nearby entities in single-player
- Movement Notes — study stamina and speed values

### Wallhack
- Item Catalog — browse items, skins, and colors
- Loadout Notes — organize inventory presets
- HUD Tweaks — cleaner health and hunger display

### Aimbot
- Sandbox Notes — segment study on any map
- Weather Control — manually switch time and weather
- Base Layout Notes — chain building steps in the editor
